How to use the tool:

1

Click the Editor button.

2

Select a pre-made Build Order from the dropdown list and then click Save & Apply.

3

Press the Play button shortly before starting a new game so the timeline begins running.

💡

Tip: It is recommended to set up a hotkey for the Play button so you can start the timeline quickly without having to click it manually.

How to edit a Build Order:

1

Open the Editor

Click the Editor button in the controls to open the interactive build order table.

2

Adjust Events

Set the timestamps (format MM:SS), enter gold/wood costs, set the current and max supply (e.g. 12 / 18), and edit the action description.

3

Choose Icons

Use the icon selector to assign original Warcraft graphics for buildings, units, heroes or upgrades to each event.

4

Save & Export

Click Save & Apply to apply your changes immediately. Use Download File to save your Build Order as a .json file.

How to import a Build Order:

1

Click the Editor button.

2

Click Paste Build Order.

3

Paste a build order list in the same format as shown in the example. You can, for example, copy a match summary from WC3.NO.

4

Click Save & Apply to use the imported Build Order.

⚠️

Important: Every new row must start with a time stamp in the format 00:00.
